# Configuracion final para microempresa

## Red

Nombre de equipo sugerido:

```text
LaCie-5big
```

Grupo:

```text
EQUIPO
```

## Protocolos

Activa:

```text
SMB
AFP si hay Macs antiguos
```

Desactiva si no se usan:

```text
FTP
SFTP
NFS
Multimedia
Time Machine
```

## Recurso compartido

Recurso base:

```text
Public
```

Para empresa es mejor asignar acceso al grupo `EQUIPO` en lugar de dejarlo abierto a toda la red.
